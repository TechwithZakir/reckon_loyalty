# Retail CRM, Membership and Loyalty on ERPNext: POS Integration for Retail Chains

Retail chains in Bangladesh want to know their customers, reward repeat purchases and connect the point of sale to the CRM. **Reckon Retail Loyalty** by Reckon Technologies Ltd. adds retail CRM, membership and loyalty to ERPNext and Frappe CRM, with an API for point-of-sale systems.

## Detailed features

### Retail CRM

- Customer records for retail, linked to your ERPNext data
- Optional Frappe CRM connection for sales follow-up

### Membership and loyalty

- Membership programmes for retail customers
- Loyalty programme that rewards repeat purchases

### POS integration

- A documented POS integration API so your point-of-sale system can read and update member and loyalty data

### Demo and onboarding

- Demo walkthrough guide for presenting the solution
- Optional demo data for a retail chain demo

### Installation

- Separate Frappe app that installs beside ERPNext without changing it
- Works with Frappe and ERPNext 15 or 16

## Built on ERPNext

Reckon Retail Loyalty is a separate Frappe app, so ERPNext stays untouched. Frappe CRM is optional.

## Who it is for

Retail chains, fashion and lifestyle brands, supermarkets and franchise businesses that want customer membership and loyalty tied to their ERP and POS.
